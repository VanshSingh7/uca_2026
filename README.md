# UCA 2026 - CSE Semester 5 Coursework
A comprehensive repository of algorithms, systems programming, and web development lab exercises.
## Modules Overview
- **C Programming**: Bitwise operations, string manipulation, comment stripper, and audit logging.
- **Java Algorithms**: Quickselect, Fibonacci sums, zero-matrix manipulation, and heap sort.
- **Data Structures**: Stacks (postfix & parentheses matching) and singly linked list operations.
- **Systems & OS**: Custom Linux signals, POSIX file stats, LRU cache simulation, and bash scripting.
- **Web Development**: HTML5 interfaces, Web Workers multithreading, and custom Promise implementation.
- **Weekly Labs**: Progressive assignments from Week 5 to Week 10 including complexity analysis charts.
## Execution: Compile C with `gcc`, Java with `javac`, and launch web modules in any modern browser.
